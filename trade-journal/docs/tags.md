# 反省タグ

タグは Notion の「失敗タグ」「良かったタグ」の選択肢と一致させる。新しいタグを足すときは Notion 側の選択肢と、この表の両方に追加する。
「関連ノウハウ」は、このリポジトリのテクニカル分析アプリ（`data.js`）の項目名で、アプリの検索欄にそのまま入れれば開ける。

## 失敗タグ

| タグ | 付ける場面 | 関連ノウハウ |
|---|---|---|
| 損切り遅れ | 決めていた損切りラインを越えても持ち続けた | 資金管理とリスクリワード / メンタル管理 |
| 損切りが早すぎ | ノイズの範囲で切り、その後は想定方向に動いた | エントリー・エグジットの基本 / 標準偏差 |
| 利確が早すぎ | トレンドが続いていたのに小さく利確した | エントリー・エグジットの基本 / 相場の3局面の使い分け |
| 利確が遅れた | 目標到達や反転シグナルの後も持ち続け、利益を減らした | ダイバージェンス / 値幅観測論 |
| 飛び乗り・高値掴み | 急騰・急落の途中で根拠なく入った | 移動平均乖離率 / ボリンジャーバンド |
| ルール外エントリー | 自分のルールにない形で入った | トレード記録・検証の習慣 |
| ナンピン | 含み損のポジションに買い増し（売り増し）した | 資金管理とリスクリワード |
| ポジション過大 | 1回の損失許容額を超える数量で入った | 資金管理とリスクリワード |
| 上位足のトレンドに逆行 | 日足・週足のトレンドと逆方向に入った | マルチタイムフレーム分析 / ダウ理論 |
| ダマシに引っかかった | ブレイクやクロスがすぐ否定された | ダマシの見分け方 / 出来高の使い方 |
| 決算・イベント跨ぎ | 決算や指標発表を意図せず跨いだ | ファンダメンタルズとの付き合い方 |
| 感情的トレード | 取り返そう・乗り遅れたくないという気持ちで入った | メンタル管理 |
| 根拠不足 | エントリー理由を一言で説明できない | 複数指標の組み合わせ方 |
| 地合い無視 | 指数全体の流れ（日経平均・S&P500など）を見ていなかった | 相場の3局面の使い分け |
| 撤退ラインを後から決めた | 買った時点では撤退条件がなく、含み損になってから決めた | 資金管理とリスクリワード |
| 保有方針と撤退基準の不一致 | 長期のつもりなのに短期の値動き基準で撤退した（またはその逆） | トレード記録・検証の習慣 |
| 下げ止まりを確認せず | 「安くなった」だけで、25日線の向き・5日線上抜け・安値切り上げを確認せずに買った | 移動平均線の基本 / グランビルの法則 |
| テーマの集中 | 同じテーマの銘柄を同時に3つ以上（スイング）持っていた | 資金管理とリスクリワード |
| 需給の確認不足 | 信用倍率・信用買い残の推移を確認しなかった | 出来高の使い方 |

## 良かったタグ

| タグ | 付ける場面 |
|---|---|
| ルール通り | エントリーから決済まで自分のルールどおり |
| 損切り徹底 | 損切りラインで迷わず切れた |
| 利益を伸ばせた | トレンドに乗ったまま引っ張れた |
| 上位足を確認 | 上位足の方向を確認してから入った |
| 待てた | 形ができるまで待ってから入った |
| 分割売買 | 分割エントリー・分割決済でリスクを抑えた |
| 資金管理OK | 損失許容額の範囲で数量を決められた |
| 撤退ラインを事前に決めた | 買う前に撤退価格と理由を決めていた |
| 安値より上で売れた | 撤退の約定が当日安値より上だった |
