| タイトル | タイトル | `決済日 銘柄コード 銘柄名 方向` / デイトレ日次は `日付 デイトレ（市場・n回）` |
| 決済日 / エントリー日 | 日付 | |
| 決済月 | セレクト | `YYYY-MM`。月別損益グラフのグループ化用。選択肢は 2024-01〜2028-12 を用意済み（それ以降は選択肢の追加が必要） |
| 市場 | セレクト | 日本株 / 米国株 |
| 銘柄コード / 銘柄名 | テキスト | |
| 方向 | セレクト | 買い / 売り（空売り） |
| 区分 | セレクト | 現物 / 信用 |
| スタイル | セレクト | デイトレ（当日決済）/ スイング（30日以内）/ 中長期 |
| 記録単位 | セレクト | 個別トレード / デイトレ日次 |
| 損益(円) | 数値（円） | 手数料控除後。米国株は約定日の為替で円換算 |
| 損益率(%) | 数値 | 損益 ÷ 取得額 |
| 損益(USD) | 数値（ドル） | 米国株のみ |
| 手数料(円) | 数値（円） | |
| 勝敗 | セレクト | 勝ち / 負け / 引き分け |
| 保有日数 / 数量 / 平均取得単価 / 平均決済単価 / 取引回数 | 数値 | 取引回数はデイトレ日次のみ |
| 失敗タグ / 良かったタグ | マルチセレクト | [tags.md](tags.md) |
| ルール遵守 | セレクト | 守れた / 一部破った / 破った |
| 反省ステータス | セレクト | 未反省 / 反省済み |
| 証券会社 | セレクト | SBI証券 / 楽天証券 / 手入力 |
| 取引ID | テキスト | 取込スクリプトが発行。重複登録の防止に使う |
| 保有想定 | セレクト | 買う時点の想定: デイトレ / スイング / 中期（1〜6か月）/ 長期（半年以上） |
| 撤退ライン(円) | 数値（円） | 損切りの価格 |
| 撤退ラインの決定 | セレクト | 買う前に決めた / 買った後に決めた / 決めていない |
| 決済理由 | セレクト | 撤退ライン到達 / 利確目標到達 / 買いの根拠が崩れた / 時間切れ / 感情・その他 |
| 買いのタイプ | マルチセレクト | 押し目・サポート反発 / 急落の反発狙い / ブレイクアウト / トレンド追随 / 業績・バリュー / その他 |
| 追加買い | セレクト | なし / 上昇後に追加 / 含み損で追加（ナンピン） |
| 25日線の向き | セレクト | 買った時点: 上向き / 横ばい / 下向き |
| イベント接近 | マルチセレクト | 買ってから3日以内: 決算前 / 政治・経済イベント前 |
| テーマ | マルチセレクト | AI・半導体 / 電子部品 / 銀行・金融 / 商社 / その他（必要に応じて追加） |
| 決済日の安値(円) / 決済日の終値(円) | 数値（円） | 撤退の執行の検証用 |
