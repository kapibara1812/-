## トレード記録 DB

- DB: https://app.notion.com/p/a5a432dffd39473287ca0949be499c4d
- data source: `collection://2f166534-a101-4545-8501-994fdf145f68`

| プロパティ | 型 | 内容 |
|---|---|---|
| タイトル | タイトル | `決済日 銘柄コード 銘柄名 方向` / デイトレ日次は `日付 デイトレ（市場・n回）` |
| 決済日 / エントリー日 | 日付 | |
| 決済月 | セレクト | `YYYY-MM`。月別損益グラフのグループ化用。選択肢は 2024-01〜2028-12 を用意済み（それ以降は選択肢の追加が必要） |
| 市場 | セレクト | 日本株 / 米国株 |
| 銘柄コード / 銘柄名 | テキスト | |
| 方向 | セレクト | 買い / 売り（空売り） |
| 区分 | セレクト | 現物 / 信用 |
| スタイル | セレクト | デイトレ（当日決済）/ スイング（30日以内）/ 中長期 |
| 記録単位 | セレクト | 個別トレード / デイトレ日次 |
| 損益(円) | 数値（円） | 手数料控除後。米国株は約定日の為替で円換算 |
| 損益率(%) | 数値 | 損益 ÷ 取得額 |
| 損益(USD) | 数値（ドル） | 米国株のみ |
| 手数料(円) | 数値（円） | |
| 勝敗 | セレクト | 勝ち / 負け / 引き分け |
| 保有日数 / 数量 / 平均取得単価 / 平均決済単価 / 取引回数 | 数値 | 取引回数はデイトレ日次のみ |
| 失敗タグ / 良かったタグ | マルチセレクト | [tags.md](tags.md) |
| ルール遵守 | セレクト | 守れた / 一部破った / 破った |
| 反省ステータス | セレクト | 未反省 / 反省済み |
| 証券会社 | セレクト | SBI証券 / 楽天証券 / 手入力 |
| 取引ID | テキスト | 取込スクリプトが発行。重複登録の防止に使う |

ビュー: 一覧 / 未反省 / 負けトレード / 月別損益（グラフ）/ 失敗パターン（グラフ）/ 市場・スタイル別（ボード）/ 全項目

## 月次振り返り DB

- DB: https://app.notion.com/p/562794ee0fbe42eba4d988a5959b2660
- data source: `collection://33c49b17-af2a-4f0b-aa2e-9974289be894`

| プロパティ | 型 |
|---|---|
| タイトル（例: 2026年10月） | タイトル |
| 対象月 | 日付（その月の1日） |
| 取引数 / 勝率(%) / プロフィットファクター / ペイオフレシオ | 数値 |
| 損益(円) / 日本株損益(円) / 米国株損益(円) / 最大ドローダウン(円) | 数値（円） |
| 多かった失敗タグ | マルチセレクト |
| 来月の重点テーマ | テキスト |

## 列を変えるとき

列名を変えた場合は `tradelog/notion_payload.py` と `tradelog/stats.py` の `FIELD_ALIASES`、このファイルを合わせて直す。
