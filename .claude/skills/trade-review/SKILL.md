# 1トレードの反省

反省の観点と書き方は `trade-journal/prompts/trade_review.md`、タグは `trade-journal/docs/tags.md` に従う。
トレード記録 data source: `collection://2f166534-a101-4545-8501-994fdf145f68`

## 手順

1. **対象を決める**: ユーザーが銘柄や日付を言えばそれを、言わなければ「反省ステータス = 未反省」の行を決済日の新しい順に取得して一覧を見せ、どれにするか選んでもらう。
2. **ページを読む**: `notion-fetch` で対象ページのプロパティと約定明細を読む。
3. **材料を集める**: チャート画像（エントリーと決済の位置が分かるもの、できれば上位足も）と、エントリー時の考え・気持ちのメモをもらう。チャートが無い場合は約定内容だけで反省し、チャートが無いことを書き添える。
4. **反省を書く**: `prompts/trade_review.md` の手順で分析し、まずチャットで本人に見せる。本人の補足があれば反映する。
5. **Notion に反映**（本人が了承したら）:
   - 本文の「エントリー根拠」「良かった点」「悪かった点」「次回気をつけること」の各見出しの下を `notion-update-page` の `update_content` で書き換える（約定明細は残す）。
   - チャート画像はチャット経由ではNotionに直接アップロードできないことがあるので、その場合は「チャート」欄にNotionアプリから画像を貼ってもらうよう案内する。
   - プロパティ `失敗タグ` `良かったタグ` `ルール遵守` を設定し、`反省ステータス` を「反省済み」にする。
6. **報告**: 反映した内容を短くまとめ、未反省の残り件数を伝える。

## 注意

- 損益などの数字はページのプロパティの値を使い、書き換えない。
- タグは `docs/tags.md` にあるものだけを使う。当てはまらない場合は付けないか、新しいタグの追加を本人に提案する。
- 今後の売買の推奨はしない。
