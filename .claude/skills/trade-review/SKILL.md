# 1トレードの反省

反省の観点と書き方は `trade-journal/prompts/trade_review.md`、タグは `trade-journal/docs/tags.md` に従う。
トレード記録 data source: `collection://2f166534-a101-4545-8501-994fdf145f68`

## 手順

1. **対象を決める**: ユーザーが銘柄や日付を言えばそれを、言わなければ「反省ステータス = 未反省」の行を決済日の新しい順に取得して一覧を見せ、どれにするか選んでもらう。
2. **ページを読む**: `notion-fetch` で対象ページのプロパティと約定明細を読む。
3. **統計用の項目を聞く**（未入力のものだけ。分からないものは空欄でよい）:
   - 保有想定（デイトレ／スイング／中期（1〜6か月）／長期（半年以上））
   - 撤退ライン（円）と、それを決めた時期（買う前に決めた／買った後に決めた／決めていない）
   - 決済理由（撤退ライン到達／利確目標到達／買いの根拠が崩れた／時間切れ／感情・その他）
   - 買いのタイプ（押し目・サポート反発／急落の反発狙い／ブレイクアウト／トレンド追随／業績・バリュー／その他。複数可）
   - 追加買い（なし／上昇後に追加／含み損で追加（ナンピン））
   - 買った時の25日線の向き、買ってから3日以内のイベント（決算前／政治・経済イベント前）、テーマ
   - 決済日の安値・終値（チャートから読み取れれば Claude が埋める）
   本人がExcelやメモで振り返りをまとめている場合は、それを読み取って埋める。
4. **材料を集める**: チャート画像（エントリーと決済の位置が分かるもの、できれば上位足も）と、エントリー時の考え・気持ちのメモをもらう。チャートが無い場合は約定内容だけで反省し、チャートが無いことを書き添える。
5. **反省を書く**: `prompts/trade_review.md` の手順で分析し、まずチャットで本人に見せる。本人の補足があれば反映する。
6. **Notion に反映**（本人が了承したら）:
   - 本文の「エントリー根拠」「良かった点」「悪かった点」「次回気をつけること」の各見出しの下を `notion-update-page` の `update_content` で書き換える（約定明細は残す）。
   - チャート画像はチャット経由ではNotionに直接アップロードできないことがあるので、その場合は「チャート」欄にNotionアプリから画像を貼ってもらうよう案内する。
   - 撤退ラインと決済日の安値・終値がある場合は、本文に「撤退ラインの検証」の表（ラインとの差・安値との差・終値との差）を入れる。
   - プロパティ `失敗タグ` `良かったタグ` `ルール遵守` と手順3の項目を設定し、`反省ステータス` を「反省済み」にする。
   - 新しい教訓が出たら「買う前チェックリスト」ページに項目を追加するか本人に提案する。
7. **報告**: 反映した内容を短くまとめ、未反省の残り件数を伝える。

## 注意

- 損益などの数字はページのプロパティの値を使い、書き換えない。
- タグは `docs/tags.md` にあるものだけを使う。当てはまらない場合は付けないか、新しいタグの追加を本人に提案する。
- 今後の売買の推奨はしない。
