# 買う前チェック

- 買う前チェックリスト: https://app.notion.com/p/40f7e1c3646581f18158d5ede4785515
- パターン仮説 data source: `collection://1e7791f3-56be-4175-b562-6150d34bea89`
- トレード記録 data source: `collection://2f166534-a101-4545-8501-994fdf145f68`

## 手順

1. チェックリストのページを `notion-fetch` で読み、現在の項目を確認する（項目は増えていくので毎回読む）。
2. 本人から、銘柄・買う理由・保有枠（スイング／長期）・株数・撤退価格と理由・チャート（あれば）を聞く。
3. 各項目を ○ / × / 未確認 で判定し、表にして見せる。チャートや本人の説明から判断できない項目は「未確認」とし、何を確認すればよいかを書く。
4. 「パターン仮説」DBで「傾向あり」「確定（ルール化）」の負けパターンに当てはまる場合は、過去の該当件数・勝率・損益を添えて指摘する。
5. ×がある場合は「見送るか株数を半分にする」というチェックリストのルールを伝える。最終判断は本人に任せる。
6. 本人が希望すれば、チェック結果を記録しておく（買った後にトレード記録の `保有想定` `撤退ライン(円)` `撤退ラインの決定` `買いのタイプ` などへ反映できるように、内容をチャットにまとめる）。

## 注意

- 銘柄の良し悪しや売買の推奨はしない。確認するのは本人のルールに沿っているかどうか。
